# T7 · Empty project list with a create action

## Prompt

When someone has no projects yet, the projects page is blank. Show a friendly message saying they have no projects, with a button to create one. Clicking the button can just show "Project created" for now.

## Expected components

Card, Button

## Rules and behavior probed

- `avoid-unnecessary-wrapper`: no stack of wrapper elements that add nothing.
- `minimize-custom-css`: supported variants are used before custom styles are written.

## Requirements checklist

- [ ] The empty message and a create button are shown.
- [ ] Clicking the button shows a "Project created" confirmation.
- [ ] The message is real text, not an image.
- [ ] Wrapper elements are only used where they serve layout or meaning.
- [ ] Little or no custom CSS is added, and no inline pixel values for padding or radius.
