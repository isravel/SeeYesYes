# T8 · Icon-only copy link action with a hint

## Prompt

On a document page, add a small copy-link control that shows only a link icon, no visible text. Pressing it should copy the page address, and people should be able to find out what it does by hovering or focusing it.

## Expected components

Button, Tooltip

## Rules and behavior probed

- The icon-only control has an accessible name.
- The hint is available on keyboard focus as well as hover.
- The hint is not the only place the purpose is stated.

## Requirements checklist

- [ ] The control shows an icon with no visible text and copies the current page address.
- [ ] It has an accessible name that says what it does, independent of the hint.
- [ ] The hint appears on hover and on keyboard focus, and Escape dismisses it.
- [ ] It is reachable and activatable with the keyboard.
- [ ] The icon itself is hidden from assistive technology.
