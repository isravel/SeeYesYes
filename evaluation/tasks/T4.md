# T4 · Invoices list with status

## Prompt

Show the customer's recent invoices as a list: invoice number, date, amount, and whether it is paid, pending, or overdue. Use this sample data: INV-104 (Mar 2, $1,200, paid), INV-105 (Mar 9, $860, pending), INV-106 (Mar 15, $2,400, overdue).

## Expected components

Table, Badge

## Rules and behavior probed

- The table has a caption or an accessible name.
- Header cells are associated with their data.
- Status is shown with the system's status styling, not raw colors.
- `token-no-raw-color`.

## Requirements checklist

- [ ] All three invoices appear with number, date, amount, and status.
- [ ] The table has a visible caption or an accessible name.
- [ ] Column headers are real header cells, and each invoice number is a row header.
- [ ] Status is conveyed with text, not color alone.
- [ ] No hard-coded color values appear in the added code.
