# T2 · Confirm before deleting a project

## Prompt

The projects page has a "Delete project" action that currently deletes immediately. Before anything is deleted, ask the person to confirm. They should be able to cancel, and nothing should be deleted unless they confirm.

## Expected components

Dialog, Button

## Rules and behavior probed

- The delete action uses the destructive variant.
- The confirmation is a named dialog.
- Escape cancels without deleting.
- Focus returns to the control that opened the dialog.

## Requirements checklist

- [ ] Choosing the delete action opens a confirmation instead of deleting.
- [ ] The confirmation has an accessible name that says what is being deleted.
- [ ] Confirm deletes the project; Cancel and Escape do not.
- [ ] The destructive action is visually and programmatically distinguishable as destructive.
- [ ] After the dialog closes, keyboard focus returns to the delete action.
- [ ] Focus stays inside the dialog while it is open.
