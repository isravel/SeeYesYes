# T6 · Split settings into sections

## Prompt

The account settings page is one long page. Split it into three sections, Profile, Security, and Billing, so only one section shows at a time and the person can switch between them. Put a short sentence of placeholder text in each section.

## Expected components

Tabs

## Rules and behavior probed

- Tabs are used rather than custom tab markup.
- Arrow keys move between tabs.

## Requirements checklist

- [ ] Profile, Security, and Billing sections exist and only the selected one is visible.
- [ ] The switcher exposes tab and tab panel semantics, with each tab tied to its panel.
- [ ] Left and Right arrow keys move between tabs.
- [ ] The tab group has an accessible name.
- [ ] No hand-built tab markup or custom arrow-key handling is added.
