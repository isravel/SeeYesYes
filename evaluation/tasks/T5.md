# T5 · Progress while settings save

## Prompt

The preferences page has an "Update preferences" button that takes about two seconds to finish (simulate it with a timer). While it is saving, make that clear to the person and stop them from pressing it again. When it finishes, tell them it saved.

## Expected components

Button, Spinner

## Rules and behavior probed

- The button uses its `loading` state, which sets `aria-busy`.
- The button's label is preserved while loading.
- No custom spinner is written when the system provides one.

## Requirements checklist

- [ ] Pressing the button starts a simulated save of about two seconds.
- [ ] While saving, the button cannot be activated again.
- [ ] The saving state is exposed to assistive technology (for example `aria-busy`).
- [ ] The button still has its label while saving.
- [ ] A completion message appears when saving finishes and is announced politely.
- [ ] No hand-written spinner or animation CSS is added.
