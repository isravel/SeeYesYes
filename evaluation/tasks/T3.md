# T3 · View profile action in a page header

## Prompt

In the page header, next to the person's name, add a "View profile" control that takes them to their profile page at `/profile`.

## Expected components

Link

## Rules and behavior probed

- `prefer-semantic-link`: navigation uses a real link, not a button that changes location.
- `avoid-custom-button`: no clickable non-interactive element such as a div with an onClick.

## Requirements checklist

- [ ] The control navigates to `/profile`.
- [ ] It is a real link element with an `href`, so it works with middle-click and "open in new tab".
- [ ] It is reachable and activatable with the keyboard (Tab and Enter).
- [ ] It has visible text that says what it does.
- [ ] No click handler on a non-interactive element is used to navigate.
