# M7.1 and M7.2 results

Date: 2026-10-16

**M7.1 (type checking, linting, focused tests, production build).** `npm run check` runs the type check (with registry generation), the component audit, lint, the unit tests, and the production build. The final gate run on Node 24.22.0 passed every step: 459 unit tests in 35 files, lint clean, and a successful build. Generation validates 29 components, 57 tokens, 8 rules, and 37 examples; the component audit matches all 29 implementations to their contracts. The earlier fresh-clone walkthrough remains in M6.7; this run verifies the current working tree on the pinned Node major.

**M7.2 (browser journeys).** `npm run test:browser` passed all 165 production-build browser tests in 33 files on Node 24.22.0 and Chromium. The suite includes theme persistence and the apply, discard, reset, refresh, two-tab, and blocked-storage paths (`theme-*`, `getting-started`); context export and agent files (`ai-context`, `agent-files`); mock recovery with Retry on every data-driven view (`data-states`, `components-catalog`, `component-detail`); keyboard interactions for every interactive component, dialogs, menus, tabs, and tooltips (`keyboard-matrix`, `overlays`, `structure`); all thirteen views, navigation, 404s, long content, and copy actions (`views`); plus the accessibility audit and the viewport matrix (M7.3, M7.5).

One test was made less timing-sensitive during this work (a Playground baseline read before hydration) and two earlier long tests got larger first-load waits; no failing test was skipped or deleted.

The final gate review added six regression cases for invalid stored revision numbers. Runtime validation now rejects unsafe integers just as the schema does, and the early bootstrap discards negative or unsafe revisions before applying any cached styles. No browser test or acceptance target was relaxed.
