# M7.7 Content review for misleading claims

Date: 2026-10-14

**Automated scan** (`tests/browser/content-claims.spec.ts`). Every sentence on all 12 fixed screens, all 29 component pages, and all 8 documentation articles, plus `/llms.txt`, `/llms-full.txt`, and the README, is checked for words that could promise something the prototype does not deliver: certification, compliance, conformance, guarantees, production readiness, "fully accessible", "verified", AI-powered claims, scanning, installing or publishing a package, hosting or deployment, proof, and general marketing superlatives. A sentence using one is accepted only if it also limits or denies the claim ("no package is published", "not a scan of any project", "does not make the theme conformant", "has not been measured yet"), or is one of three short reviewed exceptions: the principle "Show what is verified and what is still a demo", the statement that the repository runs automated checks (which is true and says they find problems rather than prove conformance), and "verified public imports". The scan found no unqualified claim.

**Manual review findings and fixes**
- **AI results.** The tagline "A design system that humans and AI can understand" and the AI Context screen could be read as a proven benefit to agents, but the evaluation that would measure it has not been run. The Overview, the AI Context screen, and the context article now say so plainly, and a test asserts it.
- **Packages and setup.** Getting Started and the setup article state that nothing is published or deployed and label the future package workflow "Not available yet"; the tests assert that no install command for a package, installer, or CDN appears.
- **Validation.** Every place that shows validation counts carries "Demo results" and says it is fixture data; no Run scan, Apply fix, upload, or repository action exists (asserted).
- **Maturity and accessibility.** All components are labeled Experimental and Not reviewed; the Accessibility screen says "0 of 29 reviewed" and that automated checks are not a review; the test confirms no component is shown as reviewed or stable without evidence.
- **Coverage.** The Overview separates calculated registry coverage from demo results and shows no combined score.
- **Performance.** The performance report states that a target is missed and the handoff lists A17 as failing; no screen claims performance results.

Verification: the four content tests pass. Human proofreading of tone and wording beyond these checks is not done.
